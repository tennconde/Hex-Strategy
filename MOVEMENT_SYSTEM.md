# Система перемещения юнитов - HexStrategy

## Обзор
Реализована полноценная система пошагового перемещения юнитов на гексагональной карте с использованием алгоритма поиска пути A*.

## Основные компоненты

### 1. TurnManager (`core/TurnManager.java`)
Менеджер системы ходов и перемещения юнитов:
- **Выбор юнита** - клик по своему юниту выделяет его
- **Построение пути** - клик по целевой клетке строит маршрут через A*
- **Анимация перемещения** - плавное движение юнита по клеткам
- **Система ходов** - ограничение действий очками движения

### 2. UnitManager (`core/UnitManager.java`)
Управление юнитами и поиск пути:
- **A* Algorithm** - поиск оптимального пути с учётом местности
- **Стоимость перемещения** - разная для типов terrain:
  - grass: 1 очко
  - forest/mountain: 2 очка
  - water/non-going-mountain: непроходимо
- **Визуализация пути** - жёлтые маркеры маршрута

### 3. HexStrategy.java
Основной класс игры с обработкой ввода:
- **ЛКМ** - выбор юнита / цель перемещения
- **ESC** - отмена перемещения
- **SPACE** - завершение хода
- **WASD** - движение камеры
- **QE** - зум камеры

## Очки движения по типам юнитов
| Тип юнита | Очки движения |
|-----------|---------------|
| warrior   | 6             |
| archer    | 7             |
| knight    | 8             |

## Как использовать

1. **Запуск игры:**
   ```bash
   ./mvnw clean javafx:run
   ```

2. **Перемещение юнита:**
   - Кликните по своему юниту (красный круг) - он выделится белой обводкой
   - Кликните по любой проходимой клетке - построится путь
   - Жёлтые квадраты покажут маршрут
   - Нажмите "Подтвердить перемещение" в UI или SPACE
   - Юнит переместится по пути с анимацией

3. **Отмена перемещения:**
   - Нажмите ESC для отмены текущего маршрута

4. **Завершение хода:**
   - Нажмите SPACE или кнопку "Следующий ход"
   - Начнётся ход ИИ (заглушка 2 секунды)

## Архитектурные решения

- **PathNode** - внутренний класс для узлов пути A*
- **Очереди действий** - FXGL.runOnce для анимации
- **Разделение ответственности**:
  - TurnManager - логика ходов и ввода
  - UnitManager - поиск пути и данные юнитов
  - HexStrategy - координация и рендеринг
